Rules (para sa Claude Code later)
  • Same theme as dashboard. Plain HTML/CSS + inline SVG, walang blur/animation/images. Touch targets ≥ 44 px, inputs 52 px.
  • Quiz: 10 random questions from the chosen language + category; 3 wrong choices from the same category. Text → Sign: still image muna (poster), isang video lang ang nagpe-play. Answer = 1 tap, then green/red + Next. Guest: walang save; user: save to quiz_attempts + quiz_answers.
  • Conversations & Quiz scores: iisang page bawat isa; user = own only, admin = all + filter. List: 20 per load + "Load more".
  • Let's Talk: title = first message; "New conversation" starts a new one. Guest conversations saved (user_id NULL), admin lang nakakakita.
  • Manage users: no delete — deactivate only. Add / Reset password = full-screen form, fields on top (keyboard-safe).
  • Admin pages redirect non-admins to the dashboard.
