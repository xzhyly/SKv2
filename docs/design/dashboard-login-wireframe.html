Rules (para sa Claude Code later)
  • Same theme: navy header, orange accent, white cards, same font and card size.
  • Pi speed: plain HTML/CSS + inline SVG; walang blur, animation, o images.
  • Login = sariling full-screen page (login.html), hindi modal. Log in / Create account = 2 tabs sa iisang page. Fields nasa itaas (≤ 340 px from top) para di matakpan ng on-screen keyboard; inputs 52 px, buttons ≥ 44 px para sa 7" touch. Back = balik sa dashboard.
  • Dashboard laging 3 cards (Learn Signs, Let's Talk, Quiz) para sa lahat. Train Gestures, View Reports, Bulk import, Manage users, All conversations, Quiz results = nasa admin menu lang (top-right chip). Menu items ≥ 44 px.
  • Train Gestures / View Reports / bulk-import: blocked din sa page mismo kung hindi admin (redirect sa dashboard), hindi lang tinatago ang card.
  • Quiz: guest at user puwede; score saved lang kung logged in.
  • Session stays logged in hanggang Log out (kiosk: auto log out after ~5 min idle — optional).
