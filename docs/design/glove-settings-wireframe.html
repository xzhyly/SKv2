Rules (para sa Claude Code)
  • Location: Admin menu → Settings (settings.html) with sections General · Voice · Glove. Admin only. This phase builds the Glove section; General/Voice can be placeholders if they don't exist yet.
  • Glove section: status (not connected / connected / reconnecting / unsupported), device info from the hello line, Connect / Disconnect, live 5-finger bars (normalized 0–1 + raw), IMU values if present, Calibrate, Use simulator toggle.
  • Calibrate: full screen, step 1 open hand 3 s, step 2 fist 3 s, Save / Redo / Reset. Stored on this kiosk.
  • No glove UI outside Settings in this phase (Let's Talk unchanged). Data available to future code via window.SKGlove.
  • Same theme, 1024×600, touch ≥ 44 px, no new libraries.
