### How each owner decision is covered

1. **Same format and place.** `candidates/<key>/<SIGNER>.json` = `{videoId, repIndex, savedAt, set, clip, source,
   frameMs}` then `<SIGNER>.info.json` = `{signer, set, frames, videoId, repIndex, savedAt, source, frameMs}`, each a
   temp file + rename, `savedAt` as PHP's `gmdate('c')`; then the meta with `candidate: {state: 'ok', signer, frames,
   repIndex, ms, source, frameMs}` (or `state: 'none', reason`), as the page's meta-only `put_video`. The clip is
   built by the page's code; only `clip.extractor.lib` names the build (`"python mediapipe 0.10.21 holistic"`), which
   `avatar_clip.php` keeps in `avatar.json`. **Source shown** in the Extract table's Source column, under the Hands
   source. The extra fields are ignored by `bulk_import.php`'s listing (DEBT 156).
2. **Reuse.** The split: `meta.split` when the page wrote it; otherwise the page's own splitter and meta builder
   through node (`avatar_node.mjs` `split`), and the meta written as the page's Start writes it (36 of 36 outputs of
   the moved `buildMeta` identical to the old page function, section 3c). **Best rep:** the page's `meta.bestRep`
   (`pickBestRep`), and Holistic only on its window (`windowStartMs`..`windowEndMs`, the page's margins: the middle
   of the rest before and after). Note: the page's rule counts **Hands** frames with the needed hands, not pose frames
   (DEBT 153); the brief's wording "frames with pose" is not what the page does, and the page's rule was kept.
3. **Same settings:** section 2.
4. **CLI:** `--avatar-signers P03,P01` (default none). Parallel workers, resume, progress + ETA. HEVC works (section 3b).
   Two files of one sign and signer: the page's rule (the first in file-name order; a later one only when every earlier
   one gave no clip or failed), in rounds.
5. **Never overwrite** a stored candidate (browser or python) without `--overwrite`, nor redo a video whose meta
   already says `none`. `saved_gestures/` is never opened by the tool.
6. **Parity:** `parity_avatar.py` (section 3a).
7. **Must not change:** see above. `buildMeta` moved, not changed (section 3c).
