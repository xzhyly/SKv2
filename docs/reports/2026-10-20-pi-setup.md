The 9 steps of `pi-setup.sh`:
1. **Packages:** apt installs Apache, PHP (mysqli, mbstring; JSON is built in), MariaDB, Chromium, unclutter, plus
   speech-dispatcher/espeak-ng for the browser voice, acl and curl.
2. **Apache:** `/var/www/html/SKR` -> the repo. Apache gets ACLs on the repo and a shared `www-data` group on
   `saved_gestures/`, `models/` and `config/`, with umask 002. `config/device.txt=pi`.
3. **PHP limits:** a `conf.d` ini with upload 16M, post 64M, memory 512M.
4. **Database:** `sining_kamay_db`, and root with an empty password via `mysql_native_password`, besides the unix
   socket (what `php/connect.php` expects). Optional `--sql` import.
5. **Display:** `video=HDMI-A-1:1024x600@60D` in `/boot/firmware/cmdline.txt` and `hdmi_force_hotplug=1`.
6. **Chromium policy:** camera/mic for localhost, autoplay, `SerialAllowAllPortsForUrls` for the glove.
7. **Kiosk launcher** `~/.local/bin/sk-kiosk.sh`:
   - all the flags asked for, plus the existing `start_kiosk.sh` ones (`--use-fake-ui-for-media-stream`,
     `--enable-speech-dispatcher`, `--password-store=basic`);
   - `--remote-debugging-port=9222` only with `--dev`;
   - started from labwc, wayfire or X11 autostart, guarded by a lock so it runs once.
8. **Desktop:** auto-login, blanking off, VNC on with `--dev` and off without it.
9. **Glove and audio:** adds the user to `dialout`, lists the serial ports and audio sinks, and prints the checks.

## Notes for the owner

- **Security:** MariaDB root has an empty password, but only on localhost (Debian binds 127.0.0.1). That is what
  `php/connect.php` needs today, the same as XAMPP. A dedicated DB user would need a `connect.php` change, which is
  out of scope here.
- `start_kiosk.sh` and `SKR_Kiosk.desktop` (hardcoded `/home/crystelle`) are left unchanged. The new launcher replaces
  them on a fresh Pi.
- A **DSI** official 7" panel is 800x480, not 1024x600: `PI-SETUP.md` troubleshooting covers it. The script assumes an
  HDMI 1024x600 LCD.
